Place your Medicare Part D zip files in this directory.

Download from:
  https://data.cms.gov/provider-summary-by-type-of-service/medicare-part-d-prescribers/medicare-part-d-prescribers-by-provider-and-drug/data

IMPORTANT — filename must match this pattern so the deploy scripts auto-detect the year:
  Medicare_Part_D_Prescribers_by_Provider_and_Drug_YYYY.zip

The CMS per-year "Download" button already names the file this way. If a file downloads
with a different name (e.g. a raw MUP_DPR_RY24_...zip), rename it to the pattern above or
the scripts will skip it.

Running in a GitHub Codespace? The zips are gitignored, so they are NOT in the container.
Download them per year with curl. The URL pattern: the MOST RECENT year is the base /data
path (no year), and OLDER years append /YYYY:
  # Most recent year (2024) - base /data path, NO year suffix
  curl -L -o "data/DemoZippedFiles/Medicare_Part_D_Prescribers_by_Provider_and_Drug_2024.zip" \
    "https://data.cms.gov/provider-summary-by-type-of-service/medicare-part-d-prescribers/medicare-part-d-prescribers-by-provider-and-drug/data"
  # Older years - append /YYYY
  curl -L -o "data/DemoZippedFiles/Medicare_Part_D_Prescribers_by_Provider_and_Drug_2023.zip" \
    "https://data.cms.gov/provider-summary-by-type-of-service/medicare-part-d-prescribers/medicare-part-d-prescribers-by-provider-and-drug/data/2023"
If a year saves a tiny (~3 KB) HTML file instead of a ~800 MB zip, right-click that year's
Download button on the CMS data page -> Copy link address, and use that URL instead.
See .devcontainer/README.md ("Getting the Medicare Data into the Codespace") for full options.
